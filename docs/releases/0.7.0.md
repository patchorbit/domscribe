# Domscribe 0.7.0

Upgrade all installed `@domscribe/*` packages together to 0.7.0.

- Query exact rendered instances, capture selection-bound annotations, and export explicit browser replay steps with portable locators. See [selection and replay](../agent-targets-and-replay.md).
- Retire handles when DOM nodes change business identity; refuse stale, ambiguous, unsupported or wrong-context targets instead of guessing.
- Capture the Vue component that owns the selected source through wrapper/Teleport ancestry, with explicit matched, nearest or unavailable ownership metadata.
- Refuse portable dialog replay without stable application context. Add a non-secret `data-ds-context` key to identify the business dialog; legacy annotations without saved identity must be recaptured.
- Redact known credential descriptors, secret-marked environment records and injected native browser Storage during privacy-enabled capture.
- Support Vite 8, mixed application Zod 3/Domscribe Zod 4 installs, cold Vite optimization and Nuxt runtime identity.

Replay covers explicit recorded actions in the main document/light DOM. It does not restore arbitrary backend data, credentials or authentication state. Source-owner resolution is currently Vue-specific; privacy redaction covers known markers, not every possible secret flow. Representative framework/browser validation is documented separately from registry-release verification. Experimental Docker cloud repair tooling is not a hosted service or GitHub issue Action, and native cloud repair authentication remains unqualified.
